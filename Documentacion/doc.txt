# Contexto
Proyecto open source de "link in bio" (estilo Linktree) para la marca ONCE Sports, que se publicará en GitHub Pages. Stack: HTML5, CSS3 y JavaScript vanilla. Sin frameworks, sin bundlers, sin package.json, sin entorno virtual y sin dependencias.

# Enfoque de diseño
El proyecto es **mobile first**: el diseño base es para móvil vertical (formato 9:16, ~390px de ancho) y las pantallas grandes se adaptan después con `min-width` media queries. Casi todo el tráfico llegará desde Instagram y TikTok en celulares. Esto aplica a toda la estructura del proyecto, aunque en esta fase no se escribe código.

- No crees nada que no esté en la lista (ni package.json, ni node_modules, ni venv).
- No hagas commit ni `git init` todavía.
