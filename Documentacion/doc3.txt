# links.json (única fuente de verdad)
Estructura:
```json
{
  "profile": { "name": "ONCE Sports" },
  "links": [
    { "id": "tienda", "label": "Tienda online", "url": "...", "featured": true, "enabled": true },
    { "id": "whatsapp", "label": "WhatsApp", "url": "...", "featured": false, "enabled": true }
  ]
}
```
- Los 4 enlaces con las URLs de arriba. `enabled: false` oculta un enlace sin borrarlo.
- Crea `links.schema.json` (JSON Schema draft 2020-12) que valide: `id` y `label` obligatorios, `url` con formato https, `featured` y `enabled` booleanos.

# js/app.js
- ES module cargado con `<script type="module" src="js/app.js">`.
- Hace `fetch("links.json")`, filtra los `enabled`, y crea los botones dentro de `#links` con `createElement` (nunca `innerHTML` con datos del JSON).
- Cada botón es un `<a>` con `href`, `target="_blank"` y `rel="noopener noreferrer"`.
- El enlace con `featured: true` recibe la clase `btn btn--primary`; los demás `btn btn--secondary`.
- Manejo de errores: si el fetch falla, deja el contenido del `<noscript>`/fallback visible y registra el error en consola.
- Menos de 60 líneas, comentarios breves, sin librerías.

# Fallback sin JavaScript
En `index.html`, dentro de `#links`, incluye un `<noscript>` con los 4 enlaces estáticos usando las mismas clases (`btn btn--primary` / `btn btn--secondary`), para que la página funcione aunque falle JS o el JSON.

# Estilos de botones
En `css/themes/default.css` define los tokens (si no existen):
```css
--btn-primary-bg: var(--color-cream);
--btn-primary-text: var(--color-ink);
--btn-secondary-bg: var(--color-black);
--btn-secondary-text: var(--color-cream);
--btn-tracking: 0.08em;
```
En `css/base.css` (usando solo variables):
- `.btn`: `display: flex; align-items: center; justify-content: center;`, `min-height: var(--button-height)` (mínimo 48px táctiles), `border-radius: var(--radius-button)`, Poppins, mayúsculas, `letter-spacing: var(--btn-tracking)`, `text-decoration: none`, `width: 100%`.
- `.btn--primary`: fondo crema, texto negro, peso 700.
- `.btn--secondary`: fondo negro, texto crema, peso 500, y el texto lleva el prefijo `/ ` mediante `::before { content: "/\00a0"; }`.
- Estados: `:hover` (ligera elevación con `transform: translateY(-2px)`), `:active` (vuelve a su posición), `:focus-visible` (outline de 3px en crema con offset de 3px).
- Transiciones de 150ms, desactivadas con `@media (prefers-reduced-motion: reduce)`.
- Los botones deben quedar por encima del "ONCE" gigante (`z-index`).
