# Política de seguridad

## Alcance

Este es un sitio estático (HTML, CSS y JavaScript vanilla) alojado en GitHub
Pages. No hay servidor propio, base de datos, cuentas de usuario ni secretos en
el código. Aun así, agradecemos cualquier aviso sobre problemas que puedan
afectar a los visitantes.

## Cómo reportar una vulnerabilidad

Por favor, **no abras un issue público** para problemas de seguridad. Informa de
forma privada a través de la pestaña **Security → Report a vulnerability** del
repositorio, o escribiendo a las personas responsables del proyecto.

Incluye, si es posible:

- Una descripción del problema y su impacto.
- Los pasos para reproducirlo.
- Navegador y sistema operativo usados.
- Cualquier prueba de concepto.

## Qué esperar

- Acuse de recibo en un plazo razonable.
- Una evaluación del problema y, si procede, una corrección.
- Crédito en el aviso, si así lo deseas.

Gracias por ayudar a mantener el sitio seguro.
